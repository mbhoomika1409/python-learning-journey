## 📌 What are Data Types in Python?

Data types in Python define the type of value stored in a variable. They help Python understand how to store, process, and perform operations on that particular data.

### Example:

age = 20
price = 99.5
name = "Bhoomika"
is_student = True

Here:

- `20` is an Integer (`int`)
- `99.5` is a Float (`float`)
- `"Bhoomika"` is a String (`str`)
- `True` is a Boolean (`bool`)

### 💡 Interview Answer:

"Data types in Python define the type of value stored in a variable. They help Python understand how to store, process, and perform operations on that particular data. For example, integers are used for whole numbers, floats for decimal values, and strings for text. Python uses the data type to determine what operations can be performed on a value."

Example:

age = 20
price = 99.5
name = "Bhoomika"

"So, data types are important because they tell Python what kind of data we are working with and what operations can be performed on that data."

# 🔢 Numeric Data Types

Numeric data types are used to store numerical values.

The numeric data types I learned today are:

## 1. Integer (`int`)

Integers are used to store whole numbers without decimal points.

### Example:

age = 20
temperature = -10
marks = 95

### Interview Explanation:

"`int` is a numeric data type used to store whole numbers. It can store both positive and negative numbers, but it does not contain decimal values."

---

## 2. Float (`float`)

Float is used to store numbers with decimal points.

### Example:

percentage = 85.5
price = 99.99
height = 5.4

### Interview Explanation:

"`float` is a numeric data type used to store decimal or floating-point values."

---

### 💡 Interview Answer for Numeric Data Types:

"Numeric data types in Python are used to store numerical values. The numeric data types I learned include `int` and `float`. `int` is used to store whole numbers, while `float` is used to store decimal values. Python automatically identifies the appropriate data type based on the value assigned to a variable."

### Example:

age = 20
percentage = 85.5

# 🔄 Sequence Data Types

Sequence data types are used to store an ordered collection of items.

The sequence data types include:

- String (`str`)
- List (`list`)
- Tuple (`tuple`)

Today, I mainly learned about Strings.

### 💡 Interview Explanation:

"A sequence data type is a type of data that stores multiple values in a specific order."

---

# 🔤 String (`str`)

A string is a sequence of characters used to represent text.

Strings can be created using:

- Single quotes `' '`
- Double quotes `" "`
- Triple quotes `''' '''` or `""" """`

### Examples:

name = "Bhoomika"
language = 'Python'

### 💡 Interview Explanation:

"A string in Python is a sequence of characters used to represent text. Strings can be created using single quotes, double quotes, or triple quotes."

---

# 📄 Multiline Strings

Triple quotes are used to create strings that span multiple lines.

### Example:

s = """I am Learning
Python String"""

print(s)

### Output:

I am Learning
Python String

The line break written inside the triple quotes is preserved when the string is printed.

Another example:

s = '''I'm a
Geek'''

print(s)

### Output:

I'm a
Geek

### 💡 Interview Explanation:

"In Python, multiline strings can be created using triple single quotes or triple double quotes. Any line breaks written inside the triple quotes are preserved when the string is printed."
